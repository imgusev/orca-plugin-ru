Русский язык для Orca

Русификатор интерфейса Orca — среды разработки агентов (ADE) от Stably AI. Переведено 98% строк: настройки, терминал, редактор, боковые панели, GitHub, GitLab, Bitbucket, Linear и Jira, браузер, навыки и автоматизации.

Russian language pack for Orca (Stably AI agent IDE / ADE). Installed as a regular plugin — the app itself is never patched.

Это не экранный диктор Orca из GNOME, не редактор MSI-пакетов Microsoft Orca и не OrcaSlicer. Речь про Orca от Stably AI — приложение для работы с флотом параллельных агентов.

Установка

  1. Settings → Plugins — включить систему плагинов.
  2. Marketplace sources → Add source, вставить адрес: 
    https://github.com/imgusev/orca-plugins.git
  3. На вкладке All найти «Русский язык для Orca» и нажать Install.
  4. Settings → Appearance → Language — выбрать русский.

Дальше Orca сама предложит обновление, когда выйдет новая версия перевода. Можно поставить и одной ссылкой — Settings → Plugins → Install plugin → Git URL, указав репозиторий с явным тегом версии.

Как это устроено

Пакет реализован штатным механизмом Orca (contributes.languagePacks): он отдаёт JSON-каталог, который приложение подмешивает в i18next. Исходники не патчатся, при обновлении Orca ничего не ломается — непереведённые строки просто показываются по-английски.

Каталог собирается из английского en.json по тегу конкретного релиза Orca, а не из main: ключ, которого нет в установленной версии, валидатор отвергает вместе со всем каталогом, и язык молча выключается. Сборка проверяет плейсхолдеры, лимит длины значений и защищённую зону приложения.

Что осталось английским

189 строк, и все осознанно: 180 из них Orca запрещает подменять языковым пакетам — это тексты, по которым пользователь решает, доверять ли плагину. Ещё около тысячи строк переведены «сами в себя»: команды, пути, переменные окружения, имена продуктов и идентификаторы состояний. Полный разбор — в UNTRANSLATED.md.

Терминология

Термины держатся единообразно: workspace — «рабочая область», runtime — «среда выполнения», review — «ревью», skill — «навык», pull request — «пул-реквест». worktree намеренно остаётся латиницей: это имя команды git worktree, а «рабочее дерево» путается с working tree.
