# Русский язык для Orca

Языковой пакет, переводящий интерфейс [Orca](https://github.com/stablyai/orca) на русский — **10 258 из 10 438 строк (98%)**.

Реализован штатным механизмом Orca (`contributes.languagePacks`): исходники приложения не патчатся, при обновлении Orca ничего не ломается. Непереведённые строки автоматически показываются по-английски — i18next делает fallback.

## Установка

Orca пока не умеет ставить языковые пакеты из маркетплейса, поэтому подключается как dev-плагин — это штатный путь, не хак.

```bash
git clone https://github.com/imgusev/orca-plugin-ru.git ~/orca-plugin-ru
```

Затем в Orca:

1. **Settings → Plugins → Development → Add path**
2. Указать путь к склонированной папке (`~/orca-plugin-ru`)
3. Подтвердить разрешения — плагин добавляет только языковой каталог, кода в нём нет
4. **Settings → Appearance → Language** — выбрать русский
5. Перезапустить Orca

Обновление:

```bash
cd ~/orca-plugin-ru && git pull
```

## Как дополнять

Orca обновляется ежедневно, новые строки приходят английскими.

```bash
cd tools
python3 extract.py          # вытащить строки из установленной Orca → en-all.json
python3 build.py            # собрать locales/ru.json и показать, чего не хватает
```

`build.py` печатает список непокрытых строк. Добавьте их в новый файл `tools/dict/*.json` — формат «английский текст» → «перевод» — и запустите сборку снова.

После обновления Orca стоит пересобрать и белый список разрешённых к переводу строк:

```bash
npx @electron/asar extract-file /Applications/Orca.app/Contents/Resources/app.asar \
  out/shared/plugins/plugin-translatable-chrome.js
grep -oE "'auto\.components\.settings\.[A-Za-z0-9_.]+'" plugin-translatable-chrome.js \
  | tr -d "'" | sort > tools/allowed-chrome.txt
```

## Защищённая зона — важно

Orca запрещает языковым пакетам подменять тексты, по которым пользователь решает, доверять ли плагину (`auto.components.settings.Plugin*`): «заблокирован», «требует проверки», источник установки, диалоги удаления.

Если хоть один такой ключ попадёт в каталог, валидатор отклонит **весь пакет целиком** с ошибкой `catalog cannot replace protected security copy`, а плагин упадёт с «The plugin stopped after an activation or worker error».

`tools/build.py` вырезает их автоматически; исключения — узкий белый список из `tools/allowed-chrome.txt`, снятый прямо из бандла Orca. Защита правильная: подмена предупреждения безопасности на успокаивающий текст — это вектор атаки.

## Структура

```

locales/ru.json       каталог переводов (785 КБ, 10 258 ключей)

tools/
  build.py            сборка каталога из словарей
```
